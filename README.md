# Sistema de calificaciones

## Descripción
Sistema de calificaciones desarrollado en Python que permite registrar y administrar las notas de cinco estudiantes. El programa muestra las calificaciones, calcula el promedio general, identifica la nota más alta y la más baja, cuenta los estudiantes aprobados y reprobados, y permite modificar una calificación.

## Objetivo
Desarrollar un programa que facilite el registro y la consulta de las calificaciones de los estudiantes mediante el uso de listas, ciclos, condicionales y funciones en Python.

## Lenguaje utilizado
Python.

## Funcionalidades desarrolladas

* Registro de cinco estudiantes y sus calificaciones.
* Validación de nombres y notas.
* Visualización de las calificaciones registradas.
* Consulta de la calificación del primer estudiante.
* Cálculo del promedio general.
* Identificación de la calificación más alta y más baja.
* Conteo de estudiantes aprobados y reprobados.
* Modificación de una calificación.
* Actualización de los resultados después de modificar una nota.

## Instrucciones para ejecutar el programa

1. Instalar Python en la computadora.
2. Descargar el archivo main.py del repositorio.
3. Abrir el archivo en Visual Studio Code.
4. Ejecutar el programa.
5. Introducir los nombres y las calificaciones solicitadas.
